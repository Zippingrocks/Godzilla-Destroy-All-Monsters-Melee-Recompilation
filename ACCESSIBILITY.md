# Accessibility

Accessibility work and reports are welcome even during early frontend bring-up.
The project currently exposes basic controller input and desktop keyboard
mapping, but it does not yet have a launcher or a complete settings interface.

## Current limitations

- Keyboard navigation is a development convenience and is not yet configurable.
- The original game's prompts and frontend accessibility remain unchanged.
- Screen-reader support, text scaling, contrast, remapping, and alternative
  input devices have not been systematically assessed.
- The recompilation is not gameplay-ready, so accessibility coverage currently
  stops at the startup and menu paths that work.

## Reporting a barrier

Use the [accessibility issue template](https://github.com/Zippingrocks/Godzilla-Destroy-All-Monsters-Melee-Recompilation/issues/new?template=accessibility_report.yml).
Describe what you were trying to do, where progress stopped, the input device or
assistive technology involved, and the tested commit. A description is enough;
screenshots and videos are optional. Do not include medical information or
retail game files.
