# Security policy

Security fixes target the current `main` branch. There are no supported public
release branches yet.

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/Zippingrocks/Godzilla-Destroy-All-Monsters-Melee-Recompilation/security/advisories/new).
Include the affected commit, impact, and reproduction steps. Do not post
security details, credentials, personal data, or retail game content in a
public issue.
