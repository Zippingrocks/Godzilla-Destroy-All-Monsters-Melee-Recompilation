# Code of conduct

## Our standards

This project is committed to a welcoming, respectful, and technically rigorous
community. Examples of positive behavior include:

- showing empathy and respect for different experience levels;
- giving specific, constructive feedback;
- documenting evidence, uncertainty, and testing honestly;
- accepting responsibility and correcting mistakes;
- focusing discussion on what is best for the project and its users.

Unacceptable behavior includes harassment, discrimination, threats, sexualized
language or attention, personal attacks, deliberate disruption, publishing
someone else's private information, or pressuring contributors to share retail
game data.

## Scope

These standards apply in repository issues, pull requests, discussions, code
review, and other spaces where someone represents this project.

## Enforcement

Project maintainers may edit or remove contributions that violate these
standards and may temporarily or permanently restrict participation. For a
confidential report, contact the maintainers through
[GitHub Security Advisories](https://github.com/Zippingrocks/Godzilla-Destroy-All-Monsters-Melee-Recompilation/security/advisories/new).
Reports will be reviewed fairly and kept confidential as far as practical.

This policy is based on the principles of the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
